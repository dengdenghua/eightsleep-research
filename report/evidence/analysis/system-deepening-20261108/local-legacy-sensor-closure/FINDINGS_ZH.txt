39704 B legacy sensor：正常本地采样、计算与报文链
范围：官方 MTK 包内 firmware-sensor-legacy.bbin；独立历史版本，不能代替现行 G0 USB/nonUSB，也不据文件名推定实机正在运行它。

一、材料与装载
原件 39704 B，SHA256 c92b8b8dce2290955c21d6030efe0323d21fad1cc6ba51d54f31756840e2a597。
完整 BBIN 映射 0x08005000；前 128 B 保留，向量表为文件 0x80 → 0x08005080。SP=0x20002000，Reset=0x0800d999（Thumb入口0x0800d998）。这个基址有三重对应：Reset 原指令是设置SP/拷贝data/清BSS；data来源0x0800eabc到RAM0x20000100..15b；字符串常量指针与文件字符串地址一致。不能套用其他 G0 固件基址。
Reset清BSS到0x200016cf；主流程打印版本2.2.12。硬件版本字段0x200001e4来自配置初始化，真实板卡值不在本轮输入中。
新 Ghidra 工程在外置盘独占建立，随后导出用readOnly/noanalysis；RAM读写属性修正只发生在新建分析工程，不修改原件。原指令/常量仍逐字节对照BBIN。Ghidra将连续主流程切成多个带尾跳转的函数，部分伪代码有unaff寄存器或错误函数尾；判断使用连续指令范围，不把伪代码函数名当C源码边界。configure/0800d87c反编译错误原样保留，不能用作成功函数复原证据。

二、启动选择和正常采样记录
公共样本队列位于0x200002e8：+0 storage、+4容量、+8单记录字节数、+0xc write计数、+0x10 read计数。080097fc按计数差和容量判满，正常拷贝记录后write++；08009500拷贝read%容量位置再read++。本轮模型只模拟无并发的合法记录快照，不研究IRQ竞争/攻击。

A. hw < 0x700
初始化容量256、记录12B、配置频率100。采样启动0800a14c把callback=0800989d与context=队列对象写入0x200012e8/ec；以频率字段配置定时器。08008a84按定时器表索引读取callback/context，满足update标志/使能后调用。索引2对应该callback槽；样本构造0800989c按以下顺序写栈记录并调用080097fc：
  +0 tick u32；+4采样0 u16；+6采样1 u16；+8增益0 u16；+10增益1 u16。
两路值由08008f0c(0/1)计算，增益来自context+0x2a/0x2c，而不是现场重新查询增益。
08008f0c按hw选择ADC DMA槽表；原始u16来源0x20000194。对正常非零参考值：
  Vref = u16((factory_vref * 3300) / reference_ADC)，整数除法；
  v = float32(float32(raw * Vref) / 4095000)；
  超过double 3.3时改为float32常量3.3；
  wireValue = u16(trunc(double(v) / 3.3 * 4095))。
原指令使用软件浮点；最后08005728是double→unsigned整数转换，不能写成四舍五入。有限算例 raw=123、factory/reference都1500时得到122；不是原ADC整数的无损直传。这里保留代码的数值尺度，不据ADC槽号标注物理位置。
增益setter080091fc：内部编码g对应记录值floor(0x30f980/(125*g+48))，精确分子0x30f980即3209600。0x2b请求分支由输入反算g，并在正常SPI调用路径更新记录字段；0x27直接编码路径也调用同setter。

B. hw >= 0x700
初始化容量128、记录24B、频率字段500、增益字段400；外部ADC初始化成功后，IRQ7向量0800af44通过0x2000015c/160调用08009f68(context)。这条链与A的定时器回调不同。
记录：+0/+4/+8/+12四个i32逻辑通道缓存，+16 tick u32，+20 gain u32。
正常有效读数从SPI取状态与数据，通道号由高位提取，要求0..3；数据以25位二补码符号扩展到i32。首通道设置组时间和增益快照，同组每通道最多写一次；四位mask全满时可以交付记录。全部到齐且delta=当前tick-首tick<2时，记录tick被写成首tick+2-delta；否则保留首tick。它不是直接每条复制当前tick，也不是本轮证明的平均采样时刻。
函数还含不完整组/统计分支，本轮只复算四个不同通道正常到齐，不把合成时间序列当实测采样率或故障发生率。递交后清tick/mask，不在这一分支清整个4通道缓存；该事实不等于已观察到坏数据。

三、0x32与0x34批次和发送格式
主循环周期检查080089a4后按hw分流：<0x700调用08009654；否则08009528。配置字段和tick用途均来自此版本，不与另一G0包的固定5条/377B或216B 0x34混同。

0x32（08009654）：排队数至少31才启动一次批次。取首记录后，只继续收集相同两路增益的记录，最多60条；遇不同增益的下一记录不弹出。
  body[0]=0x32；[1]=0x02；[2..5]=配置频率BE32；[6..9]=首记录tick BE32；
  [10..11]/[12..13]=两路增益BE16；[14..]=每条两个BE16采样。
  body长度14+4*n，正常1..60条，最大254B。31是开始阈值，不是每包固定条数；增益边界可提前结束。

0x34（08009528 / 08008ec0）：排队数至少21才开始。只续同一gain的记录；代码另有40条计数上限，但256B构造缓冲及“已写长度>247停止”先把正常包限制到30条。
  [0]=0x34；[1]=(0x20000154字段<<6)|1；[2..5]=配置频率BE32；
  [6..9]=首记录tick BE32；[10..13]=gain BE32；[14..]=每条两个BE32有符号样本位模式。
  该字段==1时选缓存通道2/3，其余选0/1；data原件0x0800eb10初始化该字段为2，所以已识别初值产生flags=0x81和0/1通道对。
  本轮已识别指令xref只见读取，不以此证明全程序不存在间接写入；模型也保留field=1的显式条件。不能把flags或通道号等同于真实床垫左右/四块板卡。
  body长度14+8*n，正常最多30条/254B；不是把四通道24B内存记录原样全发。
两个sender都有调用内tick+500的外层结束条件，检查在一次发送之后。只说500 tick限制；真实墙钟/硬件时钟漂移、并发填队列和吞吐没有实测。

四、这份固件也有实际0x33 producer
hw>=0x300进入相关功能初始化；两个I2C实例读寄存器标识均为0x1004时才设置0x20000358启用。运行逻辑在主循环0x0800d30c以后，具备实际读→缓存→快照→0x33发送链，不只是Frank有接收case。
读流程交替选择两个缓存对象，周期字段50 tick，每对象以状态0/1分离读取结果与选择下一通道，索引在3个通道间循环。读两个16位字并拼接后右移8，再乘double 2^-19、转float32写缓存。是否代表某种电容量/压力及真实通道位置，需硬件资料，代码数值本身不代替量纲。
080081b0把6个配置索引拷到快照：第一组输出顺序2/1/0，第二组0/1/2；配置表在主初始化0x0800c73c之后可复核。
500 tick路径构造27B body：opcode 0x33，当前tick BE32，两个状态各BE16，再六个(tag u8,value BE16)；tag=0..5，value是float32(slot*100)转整数的低16位。这里是正常有限数值转换，不声称全部异常数值行为。
状态计算在10000 tick路径：与上次快照逐槽比较、小于1e-9视为相等；两组各有“与上次三槽均相等”计数和“本组三槽相等”计数，真时饱和递增至65535，假时清0。
080092f0规则：与上次稳定计数>=11时，任一槽在[15.9999,16]输出1，否则2；稳定计数<11时，本组三槽相等且其计数>10输出3，否则0。状态初值0。它是这条传感缓存诊断/编码逻辑，不能凭数值或cap_sense名称改称睡眠分期、在床判定结果或物理故障证实。
两个定时分支不在同一个即时读取函数内，因此0x33包含缓存值和最近一次状态；没有证明6槽同时采样。G0 USB已恢复的类似算法仍是另一原件证据，本报告没有以名字代替字节绑定。

五、温度的本地计算与正常阈值控制
0800b044先按hw选NTC表，再从ADC DMA槽读取。RAW_TABLES保留6组表原字节、Beta、两个电阻参数和逻辑索引表。hw<=2 / ==3 / 4..0x1ff / 0x200..0x2ff / 0x300..0x4ff / >=0x500分别选6组；Beta有3435、3936、3380，分压电阻有10000和7150，不能一律写成同一板型。
正常值：mode0计算R=R6*(4095/ADC-1)，mode1计算R=R4/(4095/ADC-1)，中间为float32。ADC<50、mode1且ADC>4050、未映射slot=0x18返回-100哨兵。
  T = float32(float32(1/(ln(float32(R/10000))/Beta + 1/298.15)) - 273.15)。
ln由0800af98的z=(x-1)/(x+1)、2*(z+z^3/3+z^5/5+...)实现，累计double不再变化时结束；模型只检查正常正数，不外推全数值域。
08008d18合并两个局部值与第三参考值：float32((0.2*min(a,b)+max(a,b)+0.1*c)/1.3)。08008e6c/08da4另处理-100哨兵和多输入，0800b344按硬件/逻辑索引选择两输入或三输入组合。两个局部值相等时该式仍保留第三输入的权重；没有恢复睡眠信号融合。
主温控0800b194使用函数指针获取选定温度和既有状态：选定值为-100→状态0；若温度>target+0.5，或聚合最热值>40.5，或片内温度>66→状态2；若温度<=target-0.5且聚合最热值<=39.5且片内温度<=64→状态1；中间带保持原状态，最后调用设置状态回调。数值40.5来自0x42220000，不能误写41。随后已继续绑定这些回调：0800b3fc用context+0x20逻辑索引取温度；0800908c读context+0x21状态；08009070写该状态，但如果拟写1且context+0x22功率字段为0则改写2。模型把前述滞回提议与这一步分开，不把提议状态当成最终硬件状态。
主loop把两个启用且状态1的请求组成位掩码；单一请求选择对应输出，两者都请求时初始化选择1，并由080090f0每15000 tick在1/2间切换。08009040先清另一输出再置选定输出；0经0800902c清两个。0800901c→08008fd8按hw选逻辑pin，再08008b6c写port+0x28清位或port+0x18置位。RAW_TABLES保留4组实际port/mask：前3组在0x48000400，>=0x500组在0x48000800。这里已闭合代码寄存器去向，不据此宣称真实物理左右或温升。状态变化080090a4还发10B的0x31：tick BE32、两状态u8、电流数值BE16、当前选择u8。
片内温度08008bd4使用工厂校准字和Vref计算，并有约1度变化缓存分支；温度查询0800b408对hw>=0x300的索引8/10返回环境缓存，其他走上述NTC/合并/片内路径。环境主循环原指令0x0800d87c/0x0800d928已保留：屏蔽输入低2bit，temperature计算175.72*raw/65536-46.85，并仅在0<T<70时写缓存；humidity计算125*raw/65536-6，非负才写缓存。没有在本段见把humidity上限夹到100，不添加这一规则。公式对应语义从原指令常量与分支读取；有错误函数尾的decompile不是证据。

六、封帧与串行出口
08008304：0x7e起点、1字节body长度、body、body CRC16大端。CRC起值0x1d0f、多项式0x1021；对长度/body/CRC的0x7d和0x7e用0x7d前缀和XOR0x20编码。内部64B暂存08008124/0800810c，满或结束交080080e8→初始化指针0800ab9c。
0800ab9c在hw<0x700逐字节入串行TX队列并启用发送；>=0x700把本次暂存拷到UART DMA缓冲，配置外设0x40013828和DMA后启动。这里闭合正常字节去向；没有执行目标，也不声称对端ACK或设备在线。IRQ忙/硬件出错的所有路径未在本轮模型中复算。

七、覆盖、校验与限制
BYTE_VALIDATION逐条核导出指令字节与原BBIN，并核原件常量/表，不把“原字节相同”当作Ghidra所有代码边界正确。NORMAL_SOURCE_MAP列本轮正常链的入口、范围与主张；所有配置/命令/原输出保留。38个合成有限检查涵盖记录批次、包字段/长度、增益分界、正常MCP四通道、0x33状态与编码、CRC转义、NTC正数和滞回；不是实际固件运行、全程序等价证明或真实故障率。
已完成：该原件启动分流、两路正常样本构造/校准/缓存、32/34批次、33读数/状态/编码、NTC与温度正常判定及功率选择/GPIO出口、0x31状态编码、共同封帧与串行出口。
仍可用现有材料继续静态做：报警电机pattern与PWM配置的完整表/执行时序（已将pass8核心原导出交local-legacy-control分支继续）；硬件信息读取与所有命令的完整路由枚举；多输入哨兵分支的全组合模型、间接写者穷尽。部分源函数已保留不等于这些项目已经完成，不能直接改列“需实机”。
需要新材料/实机的：实际板型及EEPROM/flash硬件字段、ADC槽的物理传感器位置/接线、电参数校准、实际时序/速率/在线样本，以及此历史件是否被用户Pod启用。本次不访问账号、外部API或设备，不运行原厂二进制、不展开被中止日志任务。
