一、网络服务构造与 GET 入口

ce/l.Z3() 使用 AppEnvironment.getBaseUrl(appEnvironment,"client-api",默认协议) 配置 Retrofit，并注册 Moshi converter 与 OkHttpClient。
AppEnvironment.CHINA 的 domain 是 8slp.net.cn；getBaseUrl 将 subDomain 加 -proxy，默认协议为 https。
MetricsTrendsRepository 注入的 Loc/c 来自 Z3().create(Loc/c)，不是另一个 app-api Retrofit。
Loc/c.d 的 GET 路径是 v1/users/{USER_ID}/trends；返回类型 MetricsTrendsResponse。
调用者 pc/Z.invokeSuspend 传入 tz/from/to、include-main=false、include-all-sessions=true、model-version="v3"、consistent-read。
因此按本 APK 的 CHINA 配置组合为 https://client-api-proxy.8slp.net.cn/v1/users/{USER_ID}/trends。它是从构造代码恢复的地址，没有发送请求、捕获响应或验证线上可用性；"v3" 参数不能充当后台模型实现。

二、response → health → wellbeing → abnormalities

MetricsTrendsResponse.days 中的 DailyTrendsResponse 由 pc/a0 取出并调用 toEntity，进入 daily_trends 缓存。DailyTrendsResponseJsonAdapter 将 JSON health 绑定到 HealthScoreResponse。其 toDomain 依次转 breathing、heartbeat、wellbeing；wellbeing 的七个顶层字段为 value/rating/ranges/abnormalities/dayCount/daysUntilAvailable/daysUntilCalibrated。
WellBeingHealthScoreStatResponse.toDomain 直接把 abnormalities 及另外六项传给 rc/m。RawDailyTrends 转显示模型时保留这份 wellbeing；DailyTrends 的 L 槽是健康结果。
WellBeingAbnormalitiesJsonAdapter 从对象读取 hr/hrv/rr，分别交给 WellBeingDetailStats adapter；三项各自可空，并原样放入 WellBeingAbnormalities。
这里没有将 dayCount 解释成任何统计模型的历史长度；也没有把 daysUntilCalibrated 当作手机本地训练过程。

WellBeingDetailStatsJsonAdapter 的构造器固定如下八个 JSON 名称，其 fromJson 实际读取并直接构造 DTO：

  dayOfWeekStdDev         nullable Double
  dayOfWeekDeviation      nullable Double
  abnormalLowerBound     nullable Double
  abnormalUpperBound     nullable Double

编译后 Smali 已从方法起点读到 .end method（180–449）：beginObject → selectName/packed-switch → 对应 Double/Boolean adapter → endObject → 必需值检查 → invoke-direct 构造 WellBeingDetailStats。没有均值更新、方差计算、标准差比较、滤波、波形输入或模型调用。

HealthCheckHomeViewModel 的观察者把 trends、aggregate、tags、pregnancyMode 交给 updateContent。该方法从 DailyTrends.L.c.d 取得 abnormalities：

同时从既有聚合 map 选择数据序列，构造三张显示模型：
  HEART_RATE + WELLBEING_HR_UPPER；
  HRV + WELLBEING_HRV_LOWER；

这是从返回的聚合数据挑选曲线及界限序列，不是在这些分支中生成基线。代码只支持上述显示选择方向，不能把它扩展成服务器的全部异常判断规则。
