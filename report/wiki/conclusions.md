# 核心结论与验证状态

本页为结论索引。每项结论链接一个主章节；公式、调用链和原始证据在该章节维护。四个验证维度分别记录，不合并为模块完成率。

## 验证维度

- 代码恢复：指定样本中已解释的实现范围。
- 有限模型：固定假设与输入下的对照，不表示故障概率或硬件实测。
- 部署确认：分析样本是否对应实机版本、生效配置与物理通道。
- 实机验证：实际运行记录或测量；历史 API 响应只证明该次返回。
