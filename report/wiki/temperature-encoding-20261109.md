# 温度字段编码、缺值分流与加权汇总

本章接通均值之后的整数编码、另一条本地查询出口及三输入汇总分支。分析对象为冻结 g0。函数入口模型、请求响应拼装和真实设备行为分别记录。

## 两种输出格式必须分开

| 出口 | 指定路径的内容 | 不能混用的规则 |
| --- | --- | --- |
| 可选 `0x3d` 包 | 51 字节，含十二个大端 32 位原始字 | 不能按三字节字段格式解析 |
| 本地 MCU 查询 opcode `0x2a` | 按字段输出 `ID:u8 + code:BE16` | 缺值有专门编码，不直接发送 float32 `−100` |

`0x2a` 已由冻结字节中的跳转表接到 `0x0801724c`；它是本地 MCU 协议路径，不是手机云端 HTTP API。普通账号或 App 能否调用该路径，尚未建立证据。

## 三字节字段的准确编码

编码器 `0x0801ecf0` 先调用同版本 getter，再按下列规则写三个字节：

```text
若返回值恰好等于 float32(-100)：
    code = 0x00ff，若 ID == 10
    code = 0x8000，其他 ID
否则：
    scaled = float32(value × 100)
    integer = 向零截断(scaled)
    code = integer 的低 16 位
输出：ID，code高字节，code低字节
```

对本次有限值测试，缩放后在 int32 范围内；不将该公式推广为 NaN、无穷或 int32 溢出的转换合同。代码使用了真正的整数转换函数和 `SXTH`，不是四舍五入或饱和到 16 位范围。

| 输入与字段 | 代码字 | 三字节输出 |
| --- | --- | --- |
| ID 8，缺值 −100 | `0x8000` | `08 80 00` |
| ID 10，缺值 −100 | `0x00ff` | `0a 00 ff` |
| ID 8，float32(1.239) | `0x007b`，即 123 | `08 00 7b` |
| ID 8，float32(−1.239) | `0xff85`，低16位表示 −123 | `08 ff 85` |

正常槽 0–7 先经过 `[2,60]` 均值筛选；大于 7 的 getter 分支是直接取组件字段。不能把给原始字段注入的任意测试值当作槽 0–7 的可达均值。

编码本身也不是一一对应：ID 10 的 2.55 与缺值均可编码为 `00ff`；直接字段值 327.68 的测试会产生 `8000`。这是编码层的输入别名，**未证明相应字段在实机上允许或产生这些值**，还需字段业务约束和消费者解码共同判断。

## 查询的单项与批量范围不同

在已核可用状态、请求参数齐备的模型条件下：

| 请求 | 实际分支规则 |
| --- | --- |
| 单项 ID 0–11 | 请求附加 3 字节字段 |
| 单项 ID 12 | 被该单项分支拒绝，模型状态码 1 |
| ID `0xff`，门限副本为 3 | 遍历 ID 0–10，请求附加 33 字节 |
| ID `0xff`，门限副本为 4 | 遍历 ID 0–14，请求附加 45 字节 |

因此，ID 12–14 能出现在所核模式 4 的批量结果中，不等于同样支持单项查询。字段可用标记未置位时，模型返回状态码 1；缺少 opcode 后参数时返回 6。

响应附加函数 `0x08012314` 还会受组装缓冲剩余容量限制。上表是调用者请求附加的长度，不是实际链路抓到的字节数，更不是送达确认。

## 加权函数的运算顺序

`0x080185cc` 对有限输入执行：

```text
W(a,b,r) = float32((max(a,b) + 0.2×min(a,b) + 0.1×r) / 1.3)
```

输入先扩展为 double，系数、加法与除法按已解路径在 double 中计算，最后返回 float32。表达式只概括这一顺序；模型没有证明所有 IEEE 特殊值上的原厂软浮点逐位等价。

`0x0801eb90` 接收 A、B、C、R。先令 `R' = A`（当 R 恰为缺值 −100），否则 `R'=R`，再分流：

| 可用主输入 | 返回或计算 |
| --- | --- |
| 全缺 | −100 |
| 只有一路可用 | 原样返回该路 |
| A、B 可用，C 缺 | `W(A,B,R')` |
| A、C 可用，B 缺 | `W(C,A,R')` |
| B、C 可用，A 缺 | `W(C,B,R')` |
| A、B、C 均可用 | `U=W(C,A,R')`；结果为 `W(U,B,max(B,U))` |

这里的“可用”指该函数的 `−100` 相等比较分支，不等同传感质量评估。两级结构也不等同三个输入的普通均值。

## 一个需要继续绑定调用者的缺值组合

模型入口取 `A=−100、B=2、C=2、R=−100` 时，R 首先回退到 A，仍然是 −100；随后走 B/C 加权分支，得到约 **−5.8461537**，不是缺值 −100。

这证明该函数局部并不保证“参考值回退后一定有效”，也不保证所有人工入口组合的输出仍在 `[2,60]`。但它**尚不证明**两个真实调用者能形成此组合，或下游会采用该值，更不能推断实际温控影响。下一步须追输入约束及消费者，而不是直接命名为产品故障。
