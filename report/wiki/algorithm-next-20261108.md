# 算法实现范围与研究计划

系统包含多类本地处理算法，但生产心肺分离、HRV、双人融合、在床、分期及Autopilot目标生成尚缺完整实现。结果字段、版本号和输出频率不足以唯一恢复这些规则。

## 已恢复的算法层次

| 层次 | 可复核实现 | 限制 |
| --- | --- | --- |
| 传感前处理 | 滤波/增益、数值换算、缓存、温度筛选、Posture五点均值及抽取 | 物理通道、标定、实际部署及发生率未绑定 |
| 主控整理 | 时间映射、秒桶、补点、覆盖、左右归并、编码与队列 | 不等于生理质量剔除或双人分离 |
| 热控 | PID、积分回退、环境限幅、冷却上限自适应与保护 | 解释目标执行，不生成个性化睡眠策略 |
| 机械控制 | 气囊校准/反馈、床架位置与同步 | 姿态分类、鼾声识别和部分持久化生产者仍缺 |
| 手机计算 | 阶段裁剪、指标选择、分组、取整、比较和图表 | 输入已是服务器结果，不代替波形生产算法 |

## 核心生理算法的三条材料路线

| 路线 | 所需材料 | 分析入口与停止条件 |
| --- | --- | --- |
| 版本对应实现 | 有来源的部署清单、程序/模型及摘要 | 将0.1.1／3.2.1／1.2.0绑定加载入口；只有版本字符串或论文时不做生产归属推断 |

| 姿态标签生产者 | 写current_posture的程序或进程及部署配置 | 反追输入、分类、去抖和置信度；仅有0x5C遥测或标签消费者时保持writer未知 |
