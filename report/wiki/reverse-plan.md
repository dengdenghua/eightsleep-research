# 未解决问题与逆向执行计划

目标是将具体输入、处理规则、输出和部署版本对应起来。静态实现、有限模型与实机观测分别验收；函数或原件已入库不代表其所有分支已完成分析。

## 优先行动与材料条件

| 条件 | 优先动作 | 交付与停止条件 |
| --- | --- | --- |
| 现有材料可做 | SEN-06：追温度结果多出口编码与异常边界；C18：限定 A02 Fault1–4 候选 writer | 输出地址表达式、写入值与调用链；没有新入口时记录阻点，不反复扫描或声明已穷尽 |
| 设备开机联网后 | HW-01 / C12：版本绑定；API-01：短时 live 读取 | 版本与配置清单、响应状态及原始事件；持续波形、按键事件、空流和错误分开验收 |
| 取得主控访问后 | HOST-02 / SEN-01：同源 LSP → CBOR → 上传对照 | 输出通道、时间、补点、旧值与缺点对应表；不以 App 曲线替代源波形 |
| 必须取得新材料 | API-02：审计已申请的官方导出；ALG-01 / API-04：绑定生产程序、模型或运行来源 | 文件清单、哈希及版本关系；若只有结果指标，保留生产算法缺口 |

当前 C18 与 SEN-06 标为可继续静态分析；这表示可限定目标推进，不承诺现有样本必能闭合。完整任务的前置条件和验收范围以[逐项清单](roadmap.md)为准。

## 代码分析任务

**温度输出边界（SEN-06）。** SEN-05 已在指定正常条件下接通主循环、计数、窗口与3d包体；继续追整数编码、加权汇总和异常队列边界。不得把窗口模型当物理采样或生理算法。[温度窗口](temperature-cache-20261109.md)


**A02 Fault1–4（C18）。** 已定位的正常对象、容器、堆分配及输出缓冲参数不产生这些原因值；剩余动态别名不构成“不存在”的证明。继续分析须指定具体调用者、目的地址表达式或同版本故障事件。验收要求非零原因值、实际writer、触发和清除条件；不移植A00规则代替A02实现。[气囊对象与配置](accessory-resume-20261108.md)

**Keeson位置保存（C19）。** 注册回调、串口命令、快照、配置保存与诊断已区分；当前没有新的明确未审32字节提交caller。`20003fc0`仅能命名为“CRC变化分支清零的未定byte”。突破优先需要同版正常保存轨迹、位置区Flash前后样本或包含提交者的官方应用；多入口计算别名专项必须另列目标表达式。验收须连通RAM快照、32字节提交参数、目标区和完成条件。[位置与持久化边界](accessory-resume-20261108.md)

**状态、异常与并发。** 已验证R12跨侧覆盖、成功停用后的旧快照覆盖以及指定保存失败/重试顺序；仍未穷尽线程可见性、Close、取消callback、真实IO部分失败和全部Host交错。每次扩展应固定起始状态、并行操作和观察字段，再核IL与方法顺序；不得将模型计数当发生概率。[保存与停用](host-save-boundaries-20261108.md)

**传感与热控残余。** 板型setter、时钟源、PLL、整数除法和USART相关条件已有对应静态分析；回调完整传递行为、上报字段条件栈与块操作、切换过渡与丢tick、全部电气故障/历史模式组合仍未穷尽。优先结合实际revision、总线时序与原始包，不重复已闭合表项。[配置对象与条件侧](config-object-snapshot-20261108.md)

**两个接口缺口。** SEN-02的USB `0x2B` 首次请求生产者仍缺，已知重试不算首次设置；HOST-03旧波形RAW的writer/layout仍缺，`SEQNO.RAW`只是序号状态。需要对应程序或真实文件及版本。

共享日志格式缓冲/重入专项为未验收项，不纳入其他分析的完成范围。

## 实机数据采集与部署绑定

1. 在同次启动记录App、Frank、各MCU版本、硬件revision、transport与生效配置；相同MT8365不能证明外围程序相同。
2. 沿已知GET `/v1/devices/{deviceId}/live` 契约短时只读记录状态码、事件类型、时间与原消息，区分持续piezo、按键、空流与错误。
3. 具备主控访问后，保留同源LSP、CBOR、NATS配置/接收和uploader结果，逐点核对tick、通道、补点、旧值、缺值与数组数量。
4. 将请求、发送、ACK、公开状态和压力/位置按同一时间轴对齐；ACK不等于机械完成。
5. 波形、逐搏、阶段和汇总各自保留原字节；先核版本与时间定义，再做清洗或拟合。

留存查询显示查询时设备离线，没有新的在线证据。只处理已提交的官方导出申请，不重复申请。路由器上的加密流量不能直接当作已取得波形。[实时采集与截取](realtime-capture.md)

## 材料处理与验收

来源与SHA256 → 版本/配置绑定 → 入口与消费者 → 原指令/Smali/IL核对 → 有限数值或状态对照 → 更新结论、限制与任务。完整逐项要求见[任务清单](roadmap.md)，证据方法见[来源与版本边界](evidence-method.md)。
