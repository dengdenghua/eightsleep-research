# Posture 前处理：浮点残差与时间对齐

补量化 Posture A00 固件的五点均值处理。此前已解释采样入口和打包，将它与理想分组均值逐项比较。**这份附件与用户Pod的部署对应仍未知**，不得据此推断床套心肺处理或生产姿态分类。气囊与床架的实现与残余问题另列专题。

## 五点一组，但数值状态跨组保留

每通道累计器用 `sum = float32(sum + float32(x − old))` 更新，每五个已接受帧输出一次。环形数组虽在组末包含当前五个输入，累计器却不清零；前组的浮点舍入残差可以进入后组。因此理想算术下的不重叠分组均值，与实际浮点实现要区分。

| 合成输入 | 模型结果 | 说明 |
| --- | --- | --- |
| 从零状态输入五个1 | 输出1 | 清零起点的参照 |
| 先输入−8388608、8388606、8388606、8388607、8388606，再输入五个1 | 后组累计4，输出0 | 相同五个1受到历史浮点状态影响 |
| 五个8388607后接五个0 | 后组累计−1，但输出0 | 内部残差存在，最终整数仍可能相同 |
| 1、1、1、1、0及其负数对照 | 均输出0 | 均值±0.8向零截断造成的小幅量化 |

以上输入都在有符号24位范围内。六组有限例按每次运算float32取整，是静态语义的分析者模型，原厂浮点helper未动态执行；不能把见证当作实机常见误差、误差上界或睡眠准确度结论。

## 时间戳落在窗口首点

输出时间戳取当前五个已接受帧中最早一帧。假设均匀间隔为Δ，理想均值中心在首点后2Δ，凑齐窗口至少需要4Δ。条件性示例Δ=2ms时分别为4ms与8ms。

真实输入可能包括缓存重放、缺通道零值和两ADC不同步等待；没有物理采样记录，不能直接把示例当实测延迟。后续与其他传感器对齐时，必须明确使用首点、窗口中心还是处理完成时间。

## 已补和仍缺

补齐了浮点累计与理想均值的差别、整型截断以及窗口时间轴。原始代码没有因此变成多通道融合或姿态分类器。

后续要验证数值模型与发生率，需要同源accepted输入/处理输出；绑定用户设备需要同次版本和板型；生产姿态标签仍要找写入者。现有输出不携带逐通道有效性和重放标志，仅凭相同读数不能确定真实信号恒定还是缓存重用。
