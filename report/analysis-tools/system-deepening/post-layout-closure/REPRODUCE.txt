============================================================
四、本轮特有的两个坑
============================================================

  1. 路径含空格
     交付根是 /Volumes/My Passport/...，COMMAND 行无法 split。
     所有从日志重建 argv 的脚本都用 marker '/post-layout-closure/<pass> '
     定位目标起点，输出目录单独从 '-postScript ExportSensorDiff.java '
     之后切到 marker 之前。

  2. 目标地址 ≠ 所属函数
     `TARGET 0801d940 function=0801d888` 表示 0801d940 这个地址属于函数
     0801d888。统计「谁在写 0x10f0 块」时必须用 function= 字段去重
     （得到 2 个函数），用 TARGET 地址去重会得到 16 个，给读者错误印象。
     FIELD_LEDGER.json 里两个数都记：writer_functions 与
     writer_target_addresses。
