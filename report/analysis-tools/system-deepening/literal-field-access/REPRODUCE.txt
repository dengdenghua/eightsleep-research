============================================================
四、本轮特有的坑
============================================================

  1. 字面量偏移不是主对象偏移
     同一个数值（如 0x24d）可以是任何对象的字段偏移。判定必须靠「同函数内
     是否还访问了已覆盖区间的其它偏移」+「该子块在主对象里的基址」双重证据。
     08019bac 的 0x24d/0x24e 属于 0x3b48 处的 0x250 块，不是空洞 0234..0258。

  2. 伪 C 文本看不到字面量寻址
     `ldr r3,[lit]=偏移` + `ldrb r3,[r7,r3]` 在伪 C 里不出现 param_2。
     只扫伪 C 会产生假阴性，这正是空洞 1c08 此前被判无见证的原因。
