nonUSB PLL → SYSCLK → SysTick 静态解码
2026-11-08；只读静态复核。不执行固件、不连接设备/账号/网络，不改写历史证据文件，不改写 Ghidra 工程。

结论（置顶）

1. 上一轮「writer 2 的 PLL 配置解码、两个配置入口局部结构体到实际核心频率」这条缺口
   已推进到可复算层：**三个软件 HSE 输入（16 / 32 / 8MHz）经 writer2 写入的 PLL 字段
   与 `0800cd24()` 的运行时公式，全部算出 64MHz SYSCLK**。这是 nonUSB 自身字节独立
   得出的，不是把 USB 侧「三配置解码均得 64MHz」平移过来。
2. 两个配置入口构造的 14 槽位结构体只有一处不同：`s[9]`（PREDIV 字段）在
   16MHz 版是 `0x10`、32MHz 版是 `0x30`、8MHz 版是 `0`。其余 13 项完全一致，
   由 `0800c828` 把 RCC 复位到 `CFGR2 = 0x1000` 后交给 writer2。
3. 三版恒等式：`PREDIV = 2 / 4 / 1`，`PLLMUL = 24`，`PLLDIV = 3`，
   `(HSE / PREDIV) × 24 / 3` 中 `HSE / PREDIV` 恒为 8MHz，`×24 = 192MHz`，
   `/3 = 64MHz`。**PREDIV 随软件 HSE 输入同步缩放，所以 SYSCLK 不变**。
   这解释了上一轮的 K87 分界：K87 起软件 HSE 字段从 32MHz 改 16MHz，PREDIV
   也从 4 改 2，最终核心时钟与 SysTick 装载值都不变。
4. `0800cdb4` 把 SW 切到 2（PLL），第二个结构体 `s[2]=0` 使预分频索引为 0，
   `0x080241cc` 表首项为 0 → 不分频 → `0x20000250 = 64MHz`。再经 `0800995c`
   `q = 1000/step`、`N = clock/q`、`LOAD = N-1`：step=1 → 63999，step=10 → 639999，
   与既有公式校验值一致。
5. 字节核验 **1418 项检查 0 失败**（1340 条导出指令行、82 个 flash literal、
   73 个 BL、244 个直接分支、16 项预分频表、24 个 literal 常数、49 条关键指令、
   3 组 14 槽位结构体常量传播）；算术模型 **3 组输入 / 30 条断言 0 失败**。

一、writer1 先把 RCC 复位成已知态

`0800c828` 在 `080108ac` / `08010960` 开头被调用，逐字节可核：

| 寄存器 | 写入值 | 指令 |
| --- | --- | --- |
| `0x40021000` CR | `0x100` | `0800c862` |
| `0x40021008` CFGR | `0`（SW=HSI） | `0800c856` |
| `0x4002100c` CFGR2 | `0x1000` | `0800c87e` |
| `0x20000250` 时钟变量 | `16000000` | `0800c88c` |

关键：`0x1000 & 0x11c1808c = 0`。writer2 写 CFGR2 时要保留 `old & 0x11c1808c`
这些位，而 writer1 刚把旧值定成 `0x1000`，**保留项恒为 0**，因此 CFGR2 的
最终值只由结构体槽位决定，不再含未知运行时位。

二、14 槽位结构体（常量传播复算，非反编译文本抄写）

`scripts/verify_pll_chain.py` 内置一个只覆盖所用指令的 Thumb 常量传播器，
从 `movs` / `lsls` / `adds` / `str [sp,#imm]` 逐条算出每个槽位的值，
三个变体各 14 项，与期望 0 差异：

| 槽位 | 值 | 用途 |
| --- | --- | --- |
| s[0] | 9 | 功能标志位 |
| s[1] | `0x10000` | HSE 源选择 |
| s[2..5] | 0 | `080086a4(&local_40,0,0x38)` 清零后未赋值 |
| s[6] / s[7] / s[8] | 1 / 2 / 3 | LSI / 目标 SW / PLLSRC 低两位 |
| **s[9]** | **`0x10` / `0x30` / `0`** | **PREDIV 字段（唯一版本差异）** |
| s[10] | `0x18` = 24 | PLLMUL |
| s[11] | `0x60000` | CFGR2 其它字段 |
| s[12] | `0x6000000` | CFGR2 其它字段 |
| s[13] | `0x40000000` | PLLDIV 字段（bits31:29 = 2 → /3） |

`080108ac` 的 16/32MHz 分派由 `080108ba bhi 0x08010944` 决定：分支里
`movs r4,#0x30` 并写 32000000，另一路 `movs r4,#0x10` 并写 16000000；
`r4` 在 `08010910 str r4,[sp,#0x34]` 落到 s[9]。`08010960` 直接
`movs r3,#0` 写 s[9]=0，并写 8000000 到 `0x20000474`。

三、writer2 写 CFGR2 的 OR 表达式

`0800cc2c..0800cc64` 逐条可读：

```
CFGR2 = s[8] | s[9] | (old & 0x11c1808c) | s[11] | s[12] | s[13]
        | (s[10] << 8) | 0x10000000
```

代入复位态与三个变体，得到 `0x56061813` / `0x56061833` / `0x56061803`。
低两位 = 3 使 `0800cd24` 的 `(~CFGR2 & 3) == 0` 成立，选 HSE 软件输入；
bits6:4 给出 PREDIV-1；bits14:8 = `0x18`；bits31:29 = 2。

四、SYSCLK 公式（按指令移位复算，不是按伪代码猜）

`0800cd52..0800cd78`：

```
PREDIV = ((CFGR2 << 25) >> 29) + 1        // 0800cd58 / 5a / 5e
PLL输入 = (~CFGR2 & 3) == 0 ? 0x20000474 : 16000000   // 0800cd56 / 60 / 64 / 80
r0      = PLL输入 / PREDIV                // bl 08008174 @0800cd6a
PLLMUL  = (CFGR2 << 17) >> 25            // 0800cd66 / 6e
r0      = r0 × PLLMUL                    // 0800cd72 muls
PLLDIV  = (CFGR2 >> 29) + 1              // 0800cd74 / 76
SYSCLK  = r0 / PLLDIV                    // bl 08008174 @0800cd78
```

`0800cd24` 只在 `(CFGR & 0x38) == 0x10`（SWS 已切到 PLL）时走这一支；
HSE 分支直接返回软件输入，HSI 分支返回 `16000000 >> ((CR & 0x3fff) >> 11)`。
`0800cdb4` 的第二个结构体是 `[7, 2, 0, 0x4000]`：目标 SW=2（PLL）、
预分频索引 0，切换成功后调用 `0800cd24()` 并把结果右移表值写入 `0x20000250`。

五、边界（必须一起读）

- **HSE 16/32/8MHz 是固件写入 `0x20000474` 的软件输入，不是实测晶振。**
  本轮闭合的是「软件输入 → 固件计算并写入的 SYSCLK」；「物理晶振 → 实际核心
  时钟」仍需实机。若板上晶振与软件字段不一致，实际频率不同。
- 64MHz 是**条件性**结果：依赖 PLL 锁定、SW=2 切换成功且 SWS 读回 0x10、
  writer1 复位态未被其它代码改写、没有进入 `08008c04` 致命错误出口。
  静态字节不能证明这些运行时事件。
- `08008174` 的整数除法语义来自三处调用点（1000/step、clock/q、PLL 两次除法）
  都把返回值当商使用；本轮没有对除法 helper 做形式化证明。
- `step` 是 `0x20000258` 的 RAM 字节，静态未知；模型里 1 / 10 是显式假设输入。
  名义 tick 单位还要求「运行中核心时钟等于该变量且中断正常服务」。
- 切换过渡与累计 tick 损失、PLL lock 时间、中断延迟、ADC CLKIN/DRDY 与实际
  采样率仍需实机；`0800e8b4` 用同一 `0800cd24()` 算 USART 波特率，本轮只记录
  影响面，未重算波特率寄存器。
- 上一轮与更早的结论一律不改写：本页与新增「后续更新」段承担修正。
  气囊与床架仍暂缓；核心生理算法、Autopilot、姿态分类、实机绑定、音箱 DSP、
  USB `0x2B` 首次生产者与旧波形 RAW writer 保持原状。共享日志格式缓冲/重入
  专项此前被自动安全检查中止并标记未验收，本轮未重试、未改写措辞、未引用草稿。
