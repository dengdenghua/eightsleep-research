============================================================
四、取数要点
============================================================

  1. 跳转增量是相对返回地址的 int16，不是绝对地址。
     ldrsh + lsls #1 + add lr 的语义是：
       target = return_address + 2 * signed_halfword
     表基址 = 08016fdc（bl 的下一条指令），不是 08016fd8。

  2. 五个 handler 入口无 Ghidra INSN 行。
     08016e50/e70/e9c/ec8/ed4 在 08015e00..08017000 的导出里都找不到，
     也没有 bl 直接指向它们。必须从冻结字节解码。

  3. 状态 2 有两条控制流入口。
     线性路径在 08016ec2 以 b 08016e22 结束，但 08016ea8 的 bcs 跳到
     08016ec4，后面还有 2 条指令。只做线性前缀扫描会少 4B。

  4. 0x7d 的 subs 结果写入转义标志，不是状态。
     08016f2c subs r3,#0x7c 得到 1，08016f2e strb r3,[r1] 写到 r6+0x50。
     帧状态仍在 r6+0，不要混。
